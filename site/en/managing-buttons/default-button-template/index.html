Default Button Template

The default button template sets the starting point for every new button you create. Configure your brand's colors, font, and styling once here, and new buttons will begin already on brand instead of requiring the same adjustments each time.

To access the Default Button Template, click the corresponding link in the main left-hand menu:

The default button template screen contains basic options that will be used for new buttons that are created:


If you wish to reset the template back to the Klick-Zen default settings, click the "Reset" button:


The default button template only affects newly-created buttons going forward; changing this template has no effect on existing buttons
