Klick-Zen Buttons

Klick-Zen buttons are one-click action links, styled as clean, branded buttons, that you place directly inside your Zendesk emails and Help Center. Each button carries a set of ticket actions you define: update the status, add tags, insert a comment, assign the ticket, or change its priority or type. When a customer clicks, those actions are applied to their ticket instantly, with no login, no reply, and no trip through your support portal.

Every button is rendered as an image hosted by Klick-Zen, so it displays consistently in every email client, and its look is fully yours to control, from text and font to colors and borders. A single button can perform several actions at once, and placing two or more side by side turns any email into a simple choice for the customer, such as "Yes, close my ticket" or "I still need help." One click from the customer, and the ticket is updated, routed, and moving before they've even left their inbox.

Finding your buttons: search, filter and sort

A toolbar above the list lets you search, filter and sort, which is especially useful once you have many buttons:

  • Search box. Matches on button names, button text, descriptions, labels, and the contents of actions and exceptions: field values, statuses, comment text, tags, assignee, type and priority. If a button matches on something its row doesn't normally show (for example, text inside a private comment), a Matched line appears on that row showing where the match was found.
  • Label filter ("Any label"). Select one or more labels, or Unlabeled. Each option shows how many buttons it covers. This filter appears only once at least one button has a label.
  • Action/exception filter ("Any action or exception"). Select one or more of: Update ticket field, Set ticket status, Add private comment, Add public comment, Add ticket tag, Set ticket assignee, Set ticket type, Set ticket priority, Skip if: tag exists, Skip if: status equals.
  • Show dropdown: All buttons, Enabled, Disabled, In editor, Not in editor.
  • Sort dropdown: Created: oldest (default), Created: newest, Name: A to Z, Name: Z to A.

When any filter is active, the list shows "Showing X of Y buttons · Clear filters". Clearing resets the search and filters but keeps the sort order. Your search, filters and sort are remembered in that browser and come back next time you open the app there; they are not shared with other admins.

If you filter by In editor or Not in editor while editor KlickButtons are turned off in Settings, a notice reminds you that agents can't insert any buttons from the ticket editor, with a link to Settings.


What each button row shows#

  • The button's preview image, name, and description.
  • The button's labels, shown under its description.
  • An Actions line listing what the button does when clicked.
  • A Skip If line listing what exceptions will prevent a button click.
  • A flag reading Not in ticket editor: no "<label>" label when the Ticket Editor Label setting limits the editor to one label and the button doesn't carry it.
  • A link to copy the HTML snippet for insertion into triggers, automations, and macros
